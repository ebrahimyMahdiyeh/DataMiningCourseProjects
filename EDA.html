Question 1: Challenges in Analyzing Multiple Genres¶

In this dataset, each movie can have a mix of multiple genres. What challenges does this pose when analyzing the data, and what approaches do you suggest to manage it?

Hint: Consider how multi-label data differs from single-label data in analysis and visualization.

Answer for question 1¶

Analyzing movies with multiple genres introduces several challenges. First, simple genre counts become misleading since each movie may belong to multiple genres, causing the total genre count to exceed the actual number of films. Additionally, genres are not independent—some commonly co-occur, like action and adventure—which complicates statistical analysis and modeling. Visualizations like bar charts or histograms lose clarity, requiring more complex tools such as co-occurrence heatmaps or network graphs.From a modeling perspective, traditional single-label classification techniques are insufficient. Specialized methods like One-Hot or Multi-Hot Encoding, Classifier Chains, or Label Powerset are needed to handle multi-label data effectively. To address these challenges, it’s essential to use relative frequencies, explore genre relationships through correlation or association analysis, and apply machine learning models designed for multi-label classification, such as multi-label SVMs or neural networks.

import json
# Extracts language names from the 'spoken_languages' field (JSON format)
def extract_language_names(x):
    try:
        if isinstance(x, str):
            lang_list = json.loads(x)
        elif isinstance(x, list):
            lang_list = x
        else:
            return []
        return [lang.get('name') for lang in lang_list if 'name' in lang]
    except:
        return []
df['language_list'] = df['spoken_languages'].apply(extract_language_names)
all_langs = df['language_list'].explode().dropna().str.strip()
# Categorizes movies into language groups: 'Only English', 'English + Other(s)', or 'Non-English'
def categorize_language_group(lang_list):
    if not lang_list or not isinstance(lang_list, list):
        return 'Unknown'
    lang_list_clean = [lang.strip() for lang in lang_list if isinstance(lang, str)]
    if 'English' in lang_list_clean:
        if len(lang_list_clean) == 1:
            return 'Only English'
        else:
            return 'English + Other(s)'
    else:
        return 'Non-English'
df['language_group'] = df['language_list'].apply(categorize_language_group)
from scipy.stats import ttest_ind
group_english = df[df['language_group'] == 'Only English']['revenue'].dropna()
group_multilingual = df[df['language_group'] == 'English + Other(s)']['revenue'].dropna()
t_stat, p_value = ttest_ind(group_english, group_multilingual, equal_var=False)
print(f"T-statistic: {t_stat:.3f}")
print(f"P-value: {p_value:.5f}")

T-statistic: -2.830
P-value: 0.00470

An independent t-test was conducted to compare the average revenue of movies that are "Only English" versus those that are "English + Other(s)". The test yielded a t-statistic of -2.830 and a p-value of 0.00470. Since the p-value is less than 0.05, we reject the null hypothesis and conclude that there is a statistically significant difference in revenue between the two language groups. Specifically, movies that are multilingual (English + other languages) tend to earn significantly more revenue than movies that are only in English.
